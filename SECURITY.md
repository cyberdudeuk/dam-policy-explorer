# Security

Please report security problems privately, using GitHub's **Report a vulnerability** button on this repository's
Security tab. Do not open a public issue.

This supports UK government work, so you can also report through the Cabinet Office vulnerability disclosure programme:
see [Report a vulnerability on a GOV.UK system](https://www.gov.uk/help/report-vulnerability).

The explorer is a static site with a strict content security policy. Its build pins dependencies and runs every
check, including negative tests, before anything is published.
